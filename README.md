# RiskTrace

RiskTrace is an AI-powered dispute investigation and risk intelligence platform for merchants.

## Structure
- `/backend` - Spring Boot (Java 21) REST API
- `/frontend` - React (Vite) UI

## Setup Instructions

### Backend
1. Navigate to `/backend`.
2. Run `mvnw spring-boot:run` (or use your IDE).
3. The server starts on port `8080`.

### Frontend
1. Navigate to `/frontend`.
2. Run `npm install`
3. Run `npm run dev`
4. Access via browser (default: `http://localhost:5173`)
